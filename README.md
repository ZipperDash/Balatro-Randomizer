# Balatro Randomizer

A Balatro mod that generates a unique, deterministic set of randomized gameplay parameters for every run.

Instead of simply shuffling cards, **Balatro Randomizer** can change how the game behaves — from economy and shops to Jokers, Vouchers, Planets, Blinds, player resources, and more.

## Features

* Randomized economy, rewards, reroll costs, and money accumulation
* Randomized Joker costs, sell values, spawn weights, and activation behaviour
* Randomized shop and booster behaviour
* Randomized Voucher order
* Randomized Tarot, Planet, and Spectral effects
* Randomized playing card ranks and suits
* Randomized Blind properties and Boss selection
* Randomized player resources such as Hands, Discards, and Hand Size
* Deterministic randomization based on the Balatro run seed
* Extensive configuration and ready-to-use presets

## Presets

The mod includes several presets for different levels of chaos:

**Lite Instability** — A small selection of randomization features with moderate ranges
**Empty Wallet** — Money comes and goes. Mostly goes
**Joker Lottery** — Your Jokers will decide for themselves what to do and when to do it
**Parade of Planets** — A bit of cosmic randomness
**All on Red** — More difficult and less predictable Blinds
**Random Number Generator** — Experience numerical instability
**Increased Difficulty** — Just try it
**How, What and Why** — ???

You can also configure every randomization feature individually.

## Deterministic Runs

The randomization is tied to your Balatro run seed.

For example, using the same Balatro seed with the same mod version and configuration will generate the same Randomizer configuration.

**Same seed + same settings = same randomized run.**

## Installation

Requires:

* Balatro **1.0.1o-FULL**
* Steamodded

Place the `BalatroRandomizer` mod folder in your Steamodded `Mods` directory.
